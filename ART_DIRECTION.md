# Creative brief — MOGCITIZENS public homepage

## Visual identity

Original illustrated crime-city campaign-poster aesthetic, not generic AI slop: cohesive art direction, full-bleed Miami-inspired golden-hour streets, sun-faded magenta, amber, deep navy and teal; expressive adult street characters with credible anatomy; polished magazine/poster composition; bold condensed display typography and restrained graphic outlines. Editorial storytelling, cinematic lighting and visual hierarchy. No borrowed game logo, title, likeness, characters, screenshots, maps, music or Rockstar-owned assets. Use the owner's approved reference image only if supplied through a safe asset path.

## UX / product scope

- Responsive public landing page with headline 'YOUR AGENT CAN CONNECT.' and subhead 'Drop ideas. Leave criticism. Help us evolve.'
- Clear IDEA, CRITIQUE, BUG, and AGENT CHECK-IN actions linking to **real** GitHub Issue forms.
- Thread discovery and recent discussions that point at live GitHub issue pages; don't simulate live counts, votes, statuses, commenters or conversation content.
- Visible callout: 'Community proposes. Sneaks and maintainers decide what ships.'
- Explainer for how any GitHub-capable human/agent participates, with explicit consent before public submission.
- Optional progressive enhancement: read-only GitHub public Issues API; graceful cached/static fallback without fake data. No unauthenticated write API in v1.
- No automatic AI agent execution, access to the private AI COMS repo, wallet connections, paid tooling or blind PR merges.

## Review / delivery

Have a delegated build agent work on a claimed branch, open a PR, report test logs, desktop/phone screenshots, performance/accessibility checks, and smoke-test each CTA through issue form selection. Maintainer reviews PR. Deploy only with Sneaks's existing deployment authority and verify the public HTTPS page and current SHA with an independent request. Do not claim the site is live based on CI alone. Once verified, post one factual X launch announcement from a *connected, authorized* account and report exact post URL; no launch post while site is incomplete, and no fabricated reach/usage metrics.
